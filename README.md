# GitHub Unfollowers — Extensão de Navegador

Descubra quem você segue no GitHub mas não te segue de volta, e pare de seguir com um clique.

## Instalação (Chrome / Edge / Brave)

1. Abra `chrome://extensions/`
2. Ative o **Modo de desenvolvedor** (canto superior direito)
3. Clique em **Carregar sem compactação**
4. Selecione a pasta `github-unfollowers`
5. O ícone aparecerá na barra de ferramentas

## Como usar

1. Acesse [github.com/settings/tokens](https://github.com/settings/tokens) → **Generate new token (classic)**
2. Marque os escopos: `read:user` e `user:follow`
3. Cole o token no popup da extensão e clique em **Conectar**
4. Veja quem não te segue de volta na lista
5. Clique em **Parar de seguir** individualmente ou **Parar de seguir todos**

## Funcionalidades

- Lista completa de quem você segue e não te segue de volta
- Aba **Mútuos** para ver quem segue de volta
- Busca por username
- Parar de seguir individualmente ou em lote
- Design fiel ao GitHub (tema escuro)
- Token salvo localmente com segurança

## Privacidade

O token é armazenado apenas no `chrome.storage.local` do seu navegador. Nenhum dado é enviado para servidores externos além da API oficial do GitHub.
