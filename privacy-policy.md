# Política de Privacidade – GitHub Unfollowers

Última atualização: 07 de junho de 2026

## Introdução

O GitHub Unfollowers é uma extensão para Google Chrome desenvolvida para ajudar usuários do GitHub a identificar quais contas eles seguem, mas que não seguem de volta.

Esta Política de Privacidade descreve quais informações são utilizadas pela extensão e como elas são tratadas.

## Coleta de Dados

O GitHub Unfollowers não coleta, armazena, vende ou compartilha dados pessoais dos usuários.

A extensão utiliza exclusivamente informações disponibilizadas pela API oficial do GitHub para executar suas funcionalidades.

## Uso das Informações

As informações obtidas através da API do GitHub são utilizadas apenas para:

- Consultar listas de seguidores e usuários seguidos;
- Identificar contas que não seguem o usuário de volta;
- Exibir resultados ao usuário dentro da extensão;
- Permitir ações relacionadas ao gerenciamento de follows.

Nenhuma dessas informações é enviada para servidores controlados pelo desenvolvedor.

## Armazenamento Local

A extensão pode utilizar o armazenamento local disponibilizado pelo navegador (Chrome Storage) para salvar preferências ou informações necessárias ao funcionamento da extensão.

Esses dados permanecem exclusivamente no dispositivo do usuário.

## Compartilhamento de Dados

O GitHub Unfollowers não compartilha dados com terceiros.

Nenhuma informação coletada ou processada pela extensão é vendida, transferida ou utilizada para fins publicitários.

## Serviços de Terceiros

A extensão interage apenas com os serviços oficiais do GitHub por meio de sua API pública.

O uso desses serviços está sujeito aos termos e políticas do GitHub.

## Segurança

O GitHub Unfollowers foi projetado para minimizar a coleta e o tratamento de informações, reduzindo riscos relacionados à privacidade e segurança dos usuários.

## Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir melhorias ou alterações na extensão.

A versão mais recente estará sempre disponível nesta página.
